# Проект: Path of a Warrior

## Що це
Порт J2ME мобільної гри "Path of a Warrior" (Nokia, ~2006) на Godot 4.5.
Оригінальна гра — тактична RPG для телефонів формату QVGA (240×320).

## Технічні параметри
| Параметр | Значення |
|----------|---------|
| Движок | Godot 4.5 |
| Мова | GDScript |
| Роздільна здатність | 240×320 (QVGA) |
| Розмір тайлу | 27×27 px |
| Оригінал | J2ME (Java Micro Edition) |

## Оригінальні файли
- `*.java` — деcompiled Java-код (референс для порту)
- `*.MAP`, `*.arr` — бінарні файли карт і даних
- `*.mid`, `*.wav` — аудіо
- `*.png` — графіка (тайли, UI, персонажі)
- `JAVA_REFERENCE.md` — довідник по Java класах

## Стан порту
### Реалізовано ✅
- Навігація по меню (тайтл → нова гра → меню)
- Мультиінпут: touch/gamepad/клавіатура
- Рух гравця по тайлах
- Рендер карти з PNG тайлів
- Система 37 генералів
- MIDI музика (3 треки)
- Флоу місій

### Відсутнє ❌

- Парсинг бінарних файлів (.MAP, .arr, .scr)
- Система збережень
- Інвентар і магазин (логіка)
