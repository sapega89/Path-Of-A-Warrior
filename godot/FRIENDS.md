# Mercenary's Path — як запустити гру

Гра працює тільки онлайн: вона підключається до сервера, де живе твій герой.
Поруч із грою лежать два файли, які кажуть, куди підключатись:

- `server.txt` — адреса сервера (`HOST:PORT`, наприклад `130.61.10.20:28310`);
- `server.crt` — сертифікат сервера (гра довіряє тільки йому).

Обидва файли дає той, хто тримає сервер. Якщо архів зібрано з адресою, вони вже на місці.

## Windows

1. Розпакуй `MercenarysPath-windows.zip` у будь-яку теку (не запускай прямо з архіву).
2. Перевір, що в теці є `MercenarysPath.exe`, `server.txt` і `server.crt`.
3. Запусти `MercenarysPath.exe`. Якщо Windows покаже «Windows захистив ваш ПК» —
   «Докладніше» → «Однаково запустити» (гра не підписана, це нормально).

## Linux

```
mkdir MercenarysPath && tar -xzf MercenarysPath-linux.tar.gz -C MercenarysPath
cd MercenarysPath
./MercenarysPath.x86_64
```

Якщо файл не запускається — `chmod +x MercenarysPath.x86_64`. Потрібна відеокарта з OpenGL 3.3
(будь-яка звичайна з драйверами від дистрибутива).

## Як змінити сервер

Відкрий `server.txt` у Блокноті / будь-якому редакторі й заміни рядок з адресою:

```
# коментарі починаються з #
130.61.10.20:28310
```

Порт можна не писати, тоді буде 28310. Новий сервер — новий `server.crt`: поклади його поруч
із грою замість старого. Для разового запуску можна й без файлів:

```
MercenarysPath.exe -- --server 130.61.10.20:28310 --cert C:\шлях\до\server.crt
```

## Якщо щось не так

- **«Connecting...» або «No connection to the server»** — сервер вимкнений, адреса в `server.txt`
  неправильна, або порт закритий. Гра сама пробує ще раз кожні 10 с.
- **Висить на з'єднанні, хоча адреса правильна** — найчастіше не той `server.crt` (сервер
  перезапустили з новим сертифікатом). Попроси свіжий.
- **Вхід** — UserID: 4–12 латинських літер, пароль: 4–12 цифр. Перший раз — «Новий акаунт».
