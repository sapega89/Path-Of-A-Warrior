# Музика кодом

Три мелодії гри, складені й зіграні кодом, у `godot/client/assets/music/<назва>.ogg`
(де яка грає — `godot/README.md`, «Музика»). Нічого не записано: кожен інструмент — синтез, тож
музика повністю наша, без чужих семплів і ліцензій.

```
pip install numpy scipy               # і ffmpeg у PATH
python godot/tools/music/build.py              # усі три
python godot/tools/music/build.py duma         # одну
python godot/tools/music/build.py --wav DIR    # ще й .wav, щоб послухати
```

Те саме зерно (`SEED`) дає ті самі файли. Після зміни зробіть файли знову, відкрийте гру
(або `godot --headless --path godot/client --import`) і закомітьте `.ogg`.

## Файли

- `duma.py`, `pokhid.py`, `plavni.py` — мелодії: темп, такти, акорди, ноти сопілки й бандури,
  хто де вступає. Нота — назва й тривалість у долях (`("G#4", 1.5)`), можна з форшлагом
  (`("D5", 1.5, "E5")`).
- `score.py` — як пишуться ноти (назви, такти й долі) і партії, спільні для всіх мелодій:
  бандура за візерунком над акордом, фраза сопілки, хор, бурдон ліри.
- `synth.py` — інструменти: бандура (щипкова струна Карплуса — Стронга з резонансом корпусу),
  смичкові й ліра (пилка крізь резонанси), чоловічий голос (пилка крізь форманти голосних
  «а», «о», «у»), сопілка (кілька синусоїд із диханням і вібрато), дзвін (часткові тони з
  малою терцією, що б'ються), литаври, тулумбас і бубон (моди мембрани), вітер і очерет (шум).
- `mix.py` — петля: звук, що звучить за кінцем, продовжується з початку, а зала (реверберація) —
  кругова згортка, тож шва немає; гучність за ITU-R BS.1770 (LUFS) і м'яке обмеження піків.
- `build.py` — збирає, міряє й пише `.ogg`.

## Звучання

Лад — мінор і український дорійський (D E F G# A B C, підвищений четвертий ступінь, «плач»).
Гучність: «Дума» −21 LUFS, «Похід» −22, «Плавні» −23 (як мелодії, що грали досі), піки не вище
−1,5 dBFS.
