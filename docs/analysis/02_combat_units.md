## 0. TL;DR

* **Бій — real-time action прямо на карті місії**, окремого бойового екрану немає. Карта поділена на
  **кімнати 7×7 тайлів (189×189 px)** з 1-тайловою рамкою; камера **статична на кімнату** (9×9 тайлів = 243×243,
  вікно гри 240×243 з y=16). Вороги з'являються хвилями з дверей, після зачистки відкриваються виходи
  (стрілки), перехід у сусідню кімнату — миттєвий зсув камери на 7 тайлів.
* Симуляція **покрокова за тіками** (без delta-time): 1 тік = `ae.aQ[dh]` мс = 250/180/**120**/90/50 мс
  (опція *Speed*, дефолт `dh=2` → 120 мс ≈ 8.3 тік/с) — `ag.java:746-752`, `ae.java:238`.
* Керування: напрямок — **toggle-ходьба** (натиснув — йде безперервно, ще раз — стоп), **подвійне натискання — ривок**
  (24 px/тік × 3 тіки), `5/FIRE` — **3-ударне комбо**, `1/3/7/9/0` — 5 слотів навичок (MP), `*`/`#` — швидкі
  предмети (зілля/бомби), правий софт — пауза. Блоку немає; захист = i-frames (стан «hurt» і **будь-яка навичка = невразливість**).
* Стати гравця: `cz.w/x/y/z` = ATK/DEF/maxHP/maxMP = база (`m/n/o/q`) + екіпірування. Шкода = `max(1, ATK + buff − DEF − buff)`
  (+ бонус навички `ATK·lvl/aU[i]`). Рівень: `exp.arr` (199 значень, «досвід до наступного рівня»), +3 очки статів за рівень.
* **4 герої відрізняються лише головою/портретом** (`cz.aB` використовується тільки для `char_head{1..4}` і `ju_{1..4}`).
  Реальна різниця — **тип зброї** з екіпірованої зброї: `K=0` long (Blade/Pike: дальність 63 px, 3-кадрові удари) /
  `K=1` short (Claymore/Sword/Axe: 53 px, 2-кадрові).
* Вороги: `201` мечник (mon1), `203` загін із 3 мечників (той самий mon1, ×1.5 ATK), `202` лучник-турель (mon2, ставиться
  скриптом карти, не рухається), генерали `id 1..141` з `general.arr` (126 різних у даних) — гуманоїди з тими ж шарами,
  що й герой (`char_body.png` + `g_head{1..6}` + зброя), використовують ті самі 16 навичок. Бос = генерал `dz[dm].e`.
  **Союзників у бою немає.** `e1..e15.png` — це **портрети мовців у діалогах**, не вороги.
* `.SP3` = `u8 n` + `n × 6×int16 LE {srcX, srcY, w, h, anchorX, anchorY}`; малюється в `(X−anchorX, Y−anchorY)`.
  `_sk` = набір кадрів **навичок** (162 кадри), `_g` = кадри **генерала** (21 кадр). Перевірено парсером на всіх 49 файлах —
  усі кадри, на які посилаються таблиці анімацій `ae.java`, існують.

### 1.3 Атака, навички, предмети (player-facing)

* **Звичайна атака**: 3-ударне комбо; хіт на 2-му тіку анімації (`f==1`), ціль має бути в **90°-конусі перед героєм** і
  в радіусі **63 px (long) / 53 px (short)** (`ae.aK={63,53}`). 3-й удар відкидає ворога. На опції *Normal*
  (`ep=1`, «Auto Targeting») перед хітом герой автоматично повертається до найближчого ворога в радіусі 50 px
  (`ar.java:1196-1214`, виклик `c.java:1927-1928`).
* **Навички** (19 шт., рівні 1–10 у `cz.W[0..18]`, вивчаються через візити генералів `e.java:3208-3281`): ривок-удари,
  хіли, бафи ATK/DEF, серії ударів, 360°-атаки, дальні блискавки і три «ультимейти» на весь екран (з **зупинкою часу**
  ворогів і чорним/білим фоном). Повна таблиця — §2.5.
* **Предмети в бою**: `Red/Blue/H.M. Potion (S/M/L)` відновлюють 30/60/100 % maxHP/maxMP/обох; `Powerful Bomb` і
  `Handy Dynamite` кидаються на 60 px уперед і вибухають (радіус 35 px). Стек до 5 (`ag.java:3286-3324`).

### 1.4 Блок / ухилення / невразливість

* **Блоку немає.** Ухилення = ривок або будь-яка навичка.
* **Під час будь-якої навички (`e[0]≥12`) герой не отримує шкоди**: ближні атаки ворогів перевіряють `cz.e[0]<12`
  (`ar.java:1238`, `1270`, `1608-1609`), стріли пролітають (`ar.java:1737-1743`).
* **Стан «hurt» (`e[0]=9`, 7 тіків) — практично i-frames**: б'ють лише генеральські навички f=8/14/20/21 (`ar.java:1646-1660`).
* Ворог під час своєї навички (`f[0]>5`) теж невразливий (`ar.java:502-503`, `678`).
* Вороги, що входять у кімнату (`r==0`, перші 14 тіків), невразливі (`ar.java:678`, `1348-1350`, `1595-1598`).

### 1.5 Хвилі ворогів

* Кожна кімната (`au eO[]`, 19 байт у `N.arr`) має: 4 прапорці виходів, `b` = макс. живих одночасно (у всіх даних = 3),
  **чергу спавну з 6 пар `(тип, кількість)`** і `o` = генерал-подія після зачистки (`c.java:1089-1116`, `1321-1338`).
* Спавнер (`ar.d()`, `ar.java:726-741`) щотіку: якщо живих `eA < b` і черга не порожня → створює юніт на випадковій
  точці спавну біля дверей (`eu[]`, `c.java:1339-1379`), зменшує лічильник. Генерал спавниться, лише коли інших генералів
  немає (`eB==0`). Тип `201` з імовірністю 50 % стає загоном `203` (`c.java:944-945`).
* Юніт з'являється за **56 px поза дверима** і 14 тіків іде всередину без колізій (`c.java:930-939`, `947`; `ar.java:1595-1598`).
* Лучники `202` **не з'являються з черги** — їх ставить скрипт `.MAP` (op 0) на фіксовані тайли при вході в кімнату
  (`c.java:894-926`), вони не рахуються для зачистки (`eA` їх не враховує, `c.java:1013-1014`).
* **Повторний вхід у кімнату знову завантажує її чергу** (персистентного прапорця «зачищено» немає) **(висока впевненість)**.

### 1.6 Генерали та боси

* Коли зі черги виходить генерал (`id<200`): гра переходить у `bV=5, dG=1` — діалог-виклик (`event2.scr`), потім бій
  (`c.java:984-1009`, `e.java:1285-1288`).
* Генерал = гуманоїд як герой: ті самі анімації, 16 навичок, контратака 15 %, хіл ≤3 рази при HP<50 % (§3.5).
* **Бос місії** — генерал з id `dz[dm].e` (`sideinfo.arr`); при його спавні `cr=1` (`c.java:985-986`). Коли він
  помирає й ворогів не лишилось → `co=4` → «Mission Success» (`ar.java:1326-1333`, `1868-1871`).

### 2.3 Стати ворогів (`c.a(int,int)`, `c.java:1017-1039`)

Позначення `ap`: `i`=рівень, `j`=ATK, `k`=DEF, `l`=maxHP, `m`=HP, `n/o`=баф ATK/DEF (`p/q` таймери).

**Солдати** (індекс `t = type−201`: 0 мечник, 1 лучник, 2 загін):
```
L = max(1, Lp + rand(0..4) − 2)          якщо Lp < 21      (Lp = cz.l)
L = Lp + rand(0..8) − 3                   якщо Lp < 41
L = Lp + rand(0..15) − 5                  інакше
ATK = (base[t] + L) * mult[t] / 100       base = {3,2,3}, mult = {100,100,150}
DEF = L − 1
HP  = hpb[t] + 3*L                        hpb  = {7,5,7}
```
Приклад L=1: мечник ATK 4 / DEF 0 / HP 10; лучник 3/0/8; загін 6/0/10.

**Генерали** (`paramInt1==4`; `dC` з `general.arr`):
```
L   = cz.l + eD[1]            (eD[1] — «кількість» у черзі = бонус рівня, 1..60 у даних)
ATK = (dC.g + L − 1) * 6 / 5
DEF = (dC.h + L − 1) * 6 / 5
HP  = dC.i + (L − 1) * 3
```
Приклад: Wallace (`g=4,h=0,i=20`) на L=2 → ATK 6, DEF 1, HP 23. MP у ворогів немає — навички безкоштовні.

### 5.3 Python-парсер (запущено)

Повний скрипт з перехресними перевірками — **Додаток C** (зберегти як `pow_sp3.py`, запуск
`python3 -I pow_sp3.py /home/claude/pow`). Ядро:

```python
import struct

END, BLANK = 222, 180            # ae.java: кінець послідовності / невидимий кадр

def parse_sp3(path):
    data = open(path, 'rb').read()
    n = data[0]
    if len(data) != 1 + 12 * n:
        raise ValueError('bad size')
    frames = []
    for i in range(n):
        a, b, c, d, e, f = struct.unpack_from('<6h', data, 1 + 12 * i)
        frames.append({'src': (a, b, c, d), 'anchor': (e, f)})
    return frames

def load_scr(path):              # al.java: u16 count, u16 offsets[count+1], UTF-8
    d = open(path, 'rb').read()
    cnt = d[0] | d[1] << 8
    return [d[(d[2+2*i] | d[3+2*i] << 8):(d[4+2*i] | d[5+2*i] << 8)].decode('utf-8')
            for i in range(cnt)]

def blit_rect(frame, foot_x, foot_y):
    """Повертає (src_rect, dest_top_left) для атласного кадру."""
    a, b, c, d = frame['src']
    e, f = frame['anchor']
    return (a, b, c, d), (foot_x - e, foot_y - f)

def frame_for(anim_table, anim, dir8, step):
    """cz.ab[anim][dir8][step]; dir8 -> 4 сторони через aT."""
    aT = [0, 1, 1, 1, 2, 3, 3, 3]
    seq = anim_table[anim]
    seq = seq[aT[dir8]] if isinstance(seq[0], list) else seq
    return None if step >= len(seq) else seq[step]   # >=len ≡ 222 (кінець)
```

"""Reference parser for Path of a Warrior *.SP3 sprite-frame tables.

Format (reversed from ag.K(int), ag.java 3467-3482):
    u8   n                      number of frames
    n x  6 x int16 little-endian (ag.a(byte,byte), ag.java 1275-1277)
         a = src_x, b = src_y   (top-left of region inside the PNG atlas)
         c = w,     d = h       (region size)
         e = anchor_x, f = anchor_y  (pivot; dest_top_left = entity_pos - (e, f))
Draw call (c.java 306, 485-486, ar.java 1939):
    b(img, X - e, Y - f, c, d, a, b)   -> blit img[a:a+c, b:b+d] at (X-e, Y-f)
"Whole-image" effects (c.java 242-251): PNG chosen per frame through a byte table

Usage: python3 -I pow_sp3.py /path/to/pow
"""
import os
import struct
import sys

END, BLANK = 222, 180          # animation terminator / invisible frame (ae.java)


def parse_sp3(path):
    data = open(path, 'rb').read()
    n = data[0]
    if len(data) != 1 + 12 * n:
        raise ValueError('%s: size %d != 1+12*%d' % (path, len(data), n))
    frames = []
    for i in range(n):
        a, b, c, d, e, f = struct.unpack_from('<6h', data, 1 + 12 * i)
        frames.append(dict(src=(a, b, c, d), anchor=(e, f)))
    return frames

    """al.java: u16 count, u16 offsets[count+1] (LE), UTF-8 slices."""

        k = d[4 + 2 * i] | d[5 + 2 * i] << 8
        out.append(d[j:k].decode('utf-8', 'replace'))
    return out

def check_anims(name, anims, nframes):
    bad = []
    for ai_, t in enumerate(anims):
        for d, seq in enumerate(per_dir(t)):
            for fr in seq:
                if fr in (BLANK, END):
                    continue
                if not 0 <= fr < nframes:
                    bad.append((ai_, d, fr))
    print('  %-34s frames=%3d  referenced max=%3d  out-of-range=%s' % (
        name, nframes, max(fr for t in anims for s in per_dir(t) for fr in s if fr not in (BLANK, END)), bad or 'none'))
    return not bad


def main(root):
    sp3 = {os.path.basename(p)[:-4]: parse_sp3(os.path.join(root, p))
           for p in sorted(os.listdir(root)) if p.endswith('.SP3')}
    print('Parsed %d SP3 files (all sizes == 1 + 12*n)' % len(sp3))
    for name, fr in sp3.items():
        w = max(f['src'][0] + f['src'][2] for f in fr)
        h = max(f['src'][1] + f['src'][3] for f in fr)
        print('  %-16s n=%3d  atlas>=%3dx%-3d  png=%s' % (name, len(fr), w, h, ATLAS.get(name, '<per-frame table>')))

    print('\nCross-check: every frame referenced by ae.java animation tables exists in its SP3')
    ok = True
    ok &= check_anims('player anims 0..11  vs char_body', PLAYER_ANIMS[:12], len(sp3['char_body']))
    ok &= check_anims('player anims 12..30 vs char_body_sk', PLAYER_ANIMS[12:], len(sp3['char_body_sk']))
    ok &= check_anims('general f 0..5  vs g_body', GENERAL_ANIMS[:6], len(sp3['g_body']))
    ok &= check_anims('general f 6..21 vs g_body_sk', GENERAL_ANIMS[6:], len(sp3['g_body_sk']))
    ok &= check_anims('soldier eF vs mon1', SOLDIER_ANIMS, len(sp3['mon1']))
    ok &= check_anims('archer eG vs mon2', ARCHER_ANIMS, len(sp3['mon2']))
    # parallel layers must have identical frame counts
    for grp in (['char_body', 'char_head1', 'char_head2', 'char_head3', 'char_head4', 'wep_long', 'wep_short'],
                ['char_body_sk'] + ['char_head%d_sk' % i for i in range(1, 5)] + ['wep_long_sk', 'wep_short_sk'],
                ['g_body'] + ['g_head%d' % i for i in range(1, 7)] + ['wep_long_g', 'wep_short_g'],
                ['g_body_sk'] + ['g_head%d_sk' % i for i in range(1, 7)] + ['wep_long_g_sk', 'wep_short_g_sk']):
        counts = {g: len(sp3[g]) for g in grp}

    print('\nRESULT:', 'ALL CHECKS PASSED' if ok else 'FAILURES')
