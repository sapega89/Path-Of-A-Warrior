### 3. IT Команда агентів
Домовились будувати систему агентів як **окремий продукт** (глобальний рівень, MCP сервер на Python — на майбутнє).

Для поточного проекту реалізовано в `.claude/agents/`:

| Агент | Роль |
|-------|------|
| PM | Java код → технічний SPEC |
| BA | SPEC → user stories + acceptance criteria |
| Tech Lead | Архітектура + TaskCreate |
| Developer | Реалізація (.tscn → .gd) |
| Reviewer | CLAUDE.md + Godot 4.5 + Java оригінал |
| QA | Тести проти AC від BA |

**Workflow:**
```
PM → BA → Tech Lead → Developer → Reviewer → QA → ✅
```
- Таск не закривається без APPROVED від Reviewer і PASS від QA
- При FAIL/CHANGES REQUESTED — повертається до Developer

### 4. Хуки
`.claude/settings.json` — PostToolUse хук на Edit|Write:
- Після кожної зміни .gd/.tscn → agent-reviewer перевіряє автоматично
