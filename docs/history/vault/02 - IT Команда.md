# IT Команда (агенти)

Команда складається з 6 агентів. Визначення в `.claude/agents/`.

## Ролі

### PM (Product Manager)
**Файл:** `.claude/agents/pm.md`
**Інструменти:** Read, Glob, Grep
**Обов'язки:**
- Читає оригінальний Java-код
- Порівнює з поточним Godot-портом
- Пише технічні специфікації в `docs/*_SPEC.md`

**НЕ робить:** не пише код, не нарізає таски

---

### BA (Business Analyst)
**Файл:** `.claude/agents/ba.md`
**Інструменти:** Read, Glob
**Обов'язки:**
- Читає spec від PM
- Думає з точки зору гравця
- Пише user stories і acceptance criteria в `docs/*_STORIES.md`

**НЕ робить:** не читає Java-код, не пише код

---

### Tech Lead
**Файл:** `.claude/agents/tech-lead.md`
**Інструменти:** Read, Glob, Grep, Task*
**Обов'язки:**
- Читає spec і user stories
- Приймає архітектурні рішення
- Нарізає таски через TaskCreate з чіткими критеріями

**НЕ робить:** не пише код, не тестує

---

### Developer
**Файл:** `.claude/agents/developer.md`
**Інструменти:** Read, Glob, Grep, Write, Edit, Task*
**Обов'язки:**
- Реалізує один таск за раз
- Спочатку `.tscn` сцена, потім `.gd` якщо треба
- Не чіпає файли поза межами таску

**НЕ робить:** не рефакторить, не додає фічі не з таску

---

### Reviewer
**Файл:** `.claude/agents/reviewer.md`
**Інструменти:** Read, Glob, Grep, Task*
**Обов'язки:**
- Перевіряє код по чеклісту (CLAUDE.md + Godot 4.5 + Java оригінал)
- Видає APPROVED або CHANGES REQUESTED
- При CHANGES REQUESTED — повертає таск в pending

**НЕ робить:** не пише код, не запускає тести

---

### QA Engineer
**Файл:** `.claude/agents/qa.md`
**Інструменти:** Read, Glob, Grep, Bash, Task*
**Обов'язки:**
- Перевіряє проти acceptance criteria від BA
- Запускає Godot headless тести (якщо є)
- Видає PASS або FAIL
- Фінальний вердикт перед закриттям таску

**НЕ робить:** не пише код, не виправляє баги
