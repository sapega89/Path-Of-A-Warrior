## 3. Navigation

- **Up:** move selection up, wrap from 0 → 5
- **Down:** move selection down, wrap from 5 → 0
- **Confirm:** select current item
- **Back/Cancel:** go back to title

Input actions used: `menu_prev`, `menu_next`, `menu_confirm`, `ui_up`, `ui_down`, `ui_cancel`

## 4. Animations

### Carousel (slide)
- Tween-based, EASE_IN_OUT + TRANS_SINE, 0.22s
- On Down: row0 hides, row1 slides to row0 pos, row2 slides to row1 pos
- On Up: row2 hides, row1 slides to row2 pos, row0 slides to row1 pos
- Arrows hidden during animation

### Arrow bounce
- Sine wave: `sin(t * 2.0 * TAU) * 2` pixels
- arrow_up moves up, arrow_down moves down
