# Blacksmith (Кузня) — Специфікація

**Java-файли:** `as.java` (логіка + мережа), `m.java` (рендер), вхід через `bf()` в `as.java`.

---

## 1. Чотири екрани

| Екран | ho | hp | Java-метод (m.java) | Що на екрані |
|-------|----|----|---------------------|--------------|
| **Головне меню Blacksmith** | 3 | 3 | `bu()` | Перемикач Local/Server (стрілки + `ui_arrow2.png`); навігація клавішами |
| **Buy Item** | 5 | 4 | `bq()` → `bj()` + `br()` | Підменю "Normal / Special / Rare Items" → список предметів магазину (`gF[][]`), перегляд/купівля |
| **Sell Item** | 4 | 8 | `bt()` + `bv()` | Вибір джерела (Backpack / Warehouse), список предметів гравця (`cz.Y[]` або `gw[]`), вибір enchant-рівня (`ui_level.png`), введення ціни продажу; кількість слотів — 25 |
| **Cancel Sell** | 10 | 13 | `bm()` | Список 5 виставлених предметів (`gz[]`) з ціною (`gB[]`); скасування лота |

> **Enchant** і **Combine** окремих екранів у Blacksmith немає. Enchant — частина Sell: поле `EnchantLv` вибирається на екрані `bs()` (ho=7), після чого переходять до вибору ціни. Combine (item mixing) взагалі не видно в цьому меню.

## 3. Навігація між екранами

```
Головне меню гри (cM[1]=1 "Blacksmith")
  └─► bf() → Меню Blacksmith (ho=3, "Buy Item | Sell Item | Cancel Sell")
        ├─► [0] Buy Item  → aY() → ho=5 (підкатегорія Normal/Special/Rare)
        │     └─► aL()   → ho=6 (список предметів) → W()/X()/Y() → купівля
        │           BACK  → aY() → ho=5
        ├─► [1] Sell Item → bb() → aP() → ho=8 (Backpack/Warehouse)
        │     └─► ac()   → ho=7 (вибір enchant) → aQ() → ho=9 (ціна)
        │           BACK  → aP() → ho=8
        └─► [2] Cancel Sell → bg() → ho=15 (список лотів)  [окремий екран]
              BACK → bf() → ho=3
```

- BACK з будь-якого підекрану: повертає на попередній рівень (ho=3 → виходить у головне меню гри).
- Навігація у списках: `-3`/`-4` (вгору/вниз), `-5`/`53` (підтвердити), `-7` (BACK).
