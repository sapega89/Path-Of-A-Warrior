## 2. Чекліст семантики Java → Python (обов'язковий для Developer і Reviewer)

| Java | Пастка в Python | Як писати |
|---|---|---|
| `a / b` (int) | `//` округлює вниз, Java — до нуля | `idiv(a, b)` |
| `a % b` | знак результату в Python як у дільника | `imod(a, b)` |
| переповнення `int` | у Python числа безмежні | `i32(x)` там, де можливе переповнення (множення великих, хеші, RNG) |
| `long` маски (`dw`, `dx`, `dy[]`) | безмежні int, знак при зсувах | `i64(x)`, маска `& 0xFFFF_FFFF_FFFF_FFFF` |
| `(byte)x`, `(short)x`, `(char)x` | приведення немає | `i8`, `i16`, `& 0xFFFF` |
| `x >>> n` | немає оператора | `ushr32(x, n)` |
| `byte[]` зі знаком | `bytes` у Python беззнакові | порівняння з `(byte)200` → `sbyte(b) == i8(200)` або порівнювати беззнакові значення з обох боків |
| `arr[-1]` кидає виняток | Python тихо бере останній елемент | `JArray` або явна перевірка |
| `try { … } catch` як логіка (напр. `ag.J()`) | інші типи винятків | явна перевірка меж + коментар `# ORIG-BUG` |
| `switch` без `break` | fall-through не існує | переписати ланцюгом `if`, явно позначити `# fallthrough` |
| `System.arraycopy` | — | присвоєння зрізу; копіювати лише значення |
| `a = b` для масивів/об'єктів | так само посилання (OK), але `a[1] = a[0]` — аліасинг | див. DECOMP-FIX F4 |
| `'A' + 1`, `charAt` | `str` ≠ `int` | `ord`/`chr`, індексація |
| `static` поля | — | атрибути класу/модуля з тими самими іменами |
| пріоритет `<<` і `+` | однаковий з Java (`+` раніше) | переносити як є, але дужки не прибирати |
| `boolean ^ boolean` | працює, але `True + 1 == 2` | не змішувати bool та int |
