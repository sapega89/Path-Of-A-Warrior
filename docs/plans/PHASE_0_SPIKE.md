# Етап 0 — Пробний перенос (go / no-go)

**Мета:** за один робочий день довести, що підхід «1:1 з Java на Python» працює: виглядає як оригінал і запускається і на ПК, і в браузері.
**Оцінка:** 7–9 год.
**Результат:** контрольна точка **M0** + рішення «йдемо далі» або «ні».

## Команди для 0.1 (виконати у вас, у корені проєкту)

```bat
git add -A
git commit -m "Godot port frozen before Python port"
git tag godot-freeze
```

Якщо `git status` показує зайві тимчасові файли (`*.tmp` у `scenes/`), їх можна не додавати: вони не потрібні.

## Критерії «так / ні»

- **Так**, якщо:
  - титул, Main Menu і карусель Game Menu на скріншотах збігаються з оригіналом із KEmulator (до пікселя або з різницею лише в масштабуванні);
  - навігація працює;
  - браузерна збірка запускається і зберігає дані;
  - на все пішло не більше дня.
- **Ні**, якщо не вдалося хоча б одне з цього. Тоді варіант Б: Godot із тим самим підходом 1:1 (один вузол `_draw()` замість сцен на кожен екран). Прокладку `x.java` пишемо так само, тільки на GDScript.

## Що потрібно від вас

- 3–4 скріншоти оригіналу з KEmulator: лого, титул, Main Menu, Game Menu. Це еталон для порівняння.
- Перевірити `.exe` / браузер можна в кінці дня, разом зі мною.
